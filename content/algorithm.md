# algorithm

> [!summary] 一眼记住
> **/ˈælɡərɪðəm/** · *n.* · 算法；解决问题的明确步骤
> 遇见形式：“algorithm” → 可数名词原形

## 中文释义

- 为解决问题或完成计算而设计的一组明确、有序的规则或步骤。

## Explain it in English

> An algorithm is a clear set of ordered rules or steps that a computer or person follows to solve a problem.

## 形态、词族与搭配

- **变化**：algorithm；algorithms。
- **词族**：algorithmic（算法的）；algorithmically（按算法地）。
- **常见搭配**：design an algorithm；sorting algorithm；learning algorithm；algorithmic complexity。

## 学习与应用

- **阅读识别**：计算机、人工智能、数据分析和自动化系统中高频出现。
- **写作或口语**：描述用途常用 an algorithm for doing；描述类型时把领域词放在 algorithm 前。
- **易错点**：发音末尾是 /rɪðəm/；algorithm 是步骤体系，不等同于任意软件或模型。
