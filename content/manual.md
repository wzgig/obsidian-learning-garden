## 中文释义

- 手工的；手动操作的；体力劳动的
- 手册；使用说明书

## Explain it in English

> Manual describes work or control done by hand rather than automatically. As a noun, a manual is a book of instructions.

## 形态、词族与搭配

- **变化**：复数 manuals；形容词无屈折变化
- **词族**：manually（手动地）；manual labor（体力劳动）；user manual（用户手册）
- **常见搭配**：manual control, manual process, manual labor, instruction manual, user manual

## 例句

- **原创例句 1**：The backup can be started manually if the automatic schedule fails.
  中文：如果自动计划失败，可以手动启动备份。
- **原创例句 2**：The user manual explains how to reset the device safely.
  中文：用户手册说明了如何安全重置设备。

## 学习与应用

- **阅读识别**：修饰 process、control、labor 时是形容词；前有 user、instruction 时常是名词。
- **写作或口语**：适合比较 manual 与 automatic 流程，也可引用操作手册。
- **易错点**：manual 不等于 hand-written；手工操作强调人为执行，不一定是手写。
