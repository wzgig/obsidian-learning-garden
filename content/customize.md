# customize

> [!summary] 一眼记住
> **/ˈkʌstəmaɪz/** · *v.* · 定制；按需求调整
> 遇见形式：“customized” → customize 的过去式、过去分词或形容词用法

## 中文释义

- 根据某个用户、任务或场景的具体需要修改产品、系统或内容。

## Explain it in English

> To customize something is to change it so that it better fits a particular person, task, or purpose.

## 形态、词族与搭配

- **变化**：customizes；customized；customizing。
- **词族**：custom（定制的；习惯）；customization（定制）；customizable（可定制的）。
- **常见搭配**：customize settings；customize a dashboard；customized service；customize something for a user。

## 例句

- **真题语境**：已核对完整真题原句，见“来源与语境”的私有区块；公开站仅保留来源标签。
- **原创例句 1**：You can customize the review schedule for difficult words.
  中文：你可以为难词自定义复习计划。
- **原创例句 2**：The team built a customized dashboard for the research project.
  中文：团队为该科研项目制作了定制仪表板。

## 学习与应用

- **阅读识别**：软件设置、产品说明和个性化服务中常见。
- **写作或口语**：用 customize A for B 表示“为 B 定制 A”。
- **易错点**：美式拼写为 customize，英式也常见 customise；customized 可能是谓语，也可能是形容词。
